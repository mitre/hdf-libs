# hadolint-to-hdf fixtures — provenance

Recorded 2026-09-28. hadolint publishes no sample corpus of its own JSON output,
and none is carried in the SAF CLI sample corpus (mitre/saf, test/sample_data).
The inputs are therefore taken from mitre/heimdall2, whose Hadolint converter
ships two recorded reports; both were read at commit
68b34a03b8746311925766da8bbb7a7490a39cb1 (2026-09-04), the commit that added
them.

## `input/`

### `real.json`
Byte-identical to `libs/hdf-converters/sample_jsons/hadolint/sample_input_report/heimdall_dockerfile.hadolint.json`
in mitre/heimdall2 at the commit above. Four findings against one Dockerfile,
covering three distinct rules at two severity levels, including one rule that
fires twice (DL3041 at lines 15 and 42) so the group-by-rule path is exercised.

### `shellcheck.json`
Byte-identical to `libs/hdf-converters/sample_jsons/hadolint/sample_input_report/heimdall_dockerfile.hadolint_shellcheck.json`
in mitre/heimdall2 at the commit above. Six findings against one Dockerfile,
adding an SC rule — hadolint surfaces shellcheck findings in the same report —
and a second rule that fires twice.

### `empty.json`
Synthetic by construction: the literal `[]`. hadolint's JSON formatter folds
zero results to an empty array, so this is the exact shape of a clean run. Named
with the `empty.` prefix, which exempts it from the golden-coverage guard.

## `expected/`
Generated by this repository's converters, not sourced. Regenerate with
`go test ./converters/hadolint-to-hdf/... -run TestSnapshots -update`.

## Tool and version, read from the file itself (2026-09-28)
- `real.json`, `shellcheck.json` — a bare JSON array of hadolint findings, each
  carrying only `code`, `column`, `file`, `level`, `line` and `message`.
  hadolint's JSON formatter emits no tool name, version or run metadata of any
  kind (`src/Hadolint/Formatter/Json.hs`), so the producing version is not
  determinable from file content and is not claimed here.
- Both files are pretty-printed. hadolint writes compact single-line JSON with
  no trailing newline, so these were reformatted upstream; the field names,
  types and values are unchanged.

## Schema
hadolint publishes no JSON Schema for this output. The shape is an aeson
encoding of the `JsonFormat` record in `src/Hadolint/Formatter/Json.hs`, which
was read directly to confirm the six-field contract (2026-09-28). Nothing is
vendored here, so this directory carries no `provenance.json`.
