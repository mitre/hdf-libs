## Schema

Semgrep publishes the JSON Schema for `--json` output in semgrep/semgrep-interfaces, tagged per release. The fixtures report `version` 1.174.0, so that tag's `semgrep_output_v1.jsonschema` is vendored here as `semgrep_output_v1-1.174.0.schema.json` and recorded in `provenance.json`.

Validation (ajv, 2026-09-20): all four inputs validate. The schema is JSON Schema 2020-12 and encodes error types as tuples (`prefixItems`), which gojsonschema does not implement — it reports `errors.json` as failing the `oneOf`, an engine artifact, not a defect in the file; ajv is the engine of record for this schema.
