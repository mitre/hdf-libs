# OSCAL Plan of Action & Milestones schema — provenance

Two official NIST OSCAL POA&M JSON Schemas validate this converter's output in
its tests. The converter emits `"oscal-version": "1.1.2"`, so its output is
validated against that declared version. It is also validated against 1.2.3,
the current release, because 1.2.x applies constraints 1.1.2 does not (for
example, non-empty `MarkupLineDatatype` titles), and a consumer validating
against the current release must not receive a document it rejects.

- **Release:** usnistgov/OSCAL `v1.1.2`
