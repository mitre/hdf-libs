TestResult header, target facts, and score are untouched. Every distinct output shape the full file produced is still produced, and the kept
requirements are byte-identical to their pre-trim golden entries; only the volume changed. Text was removed, never edited, so the retained
content is still verbatim upstream. The full file is in this repository's history before that date if a volume test ever needs it.

## Schema

XCCDF 1.2 has an XSD and it is vendored at `hdf-to-xccdf/schemas/xccdf_1.2.xsd` (with the CPE and `xml.xsd` schemas it imports; see that directory's `provenance.json`); libxml2 compiles it in the hdf-to-xccdf tests. It is not copied here. The ARF 1.1 XSD for `arf-minimal.xml` (NIST, `asset-reporting-format_1.1.0.xsd`) is vendored here and recorded in `provenance.json`; it imports the asset-identification and reporting-core schemas by relative path, which are not vendored, so it is hash-checked but not compiled.
