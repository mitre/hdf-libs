### `anchore_grype.json`

### `empty.json`
Synthetic by construction: an empty or no-findings document used to
exercise the nothing-to-convert path. Not sourced from anywhere.

### `tensorflow.json`
Derived from heimdall2 `libs/hdf-converters/sample_jsons/anchore_grype_mapper/sample_input_report/tensorflow.json`, of which this file was a
byte-identical copy until 2026-09-14, when it was trimmed from 328 matches (7.5 MB) to 26: two per distinct (severity, package type, fix state)
combination, keeping the `descriptor`, `source` and `distro` blocks whole. The converter output was profiled before and after across statuses,
impacts, ecosystems, description labels, tag keys and requirement keys and matched on every dimension; only the count dropped. Text was removed,
never edited, so the retained matches are verbatim upstream. The full file is in this repository's history before that date.

### `directory_scan.json`
Real grype 0.117.0 output from an actual `grype dir:. -o json` run
(2026-09-20) over a one-line `requirements.txt` pinning `Jinja2==2.10`.
Captured to cover the directory-scan shape the four image fixtures never
exercised: `source.type` is `directory` and `source.target` is the bare
string `"."` (not the image object) — the shape that used to hard-fail the
Go converter. The scan was run from inside the target dir so
every path is relative; the only machine-local values, grype's DB cache-dir
under `descriptor.configuration.db.cache-dir` and `descriptor.db.status.path`,
were replaced with `/grype-cache/db` (converter-irrelevant metadata). No
other bytes were altered.
